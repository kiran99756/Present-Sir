Present Sir is a college dashboard where students mark attendance with their time and GPS location, and teachers manage classes, students, announcements and assignments. It is a single index.html file written in plain HTML, CSS and JavaScript, hosted on GitHub Pages, and it talks to Supabase through the supabase-js library loaded from a CDN. The browser's Geolocation API gives the student's position, and the app measures the distance to the class or college location with the haversine formula to mark each entry on site or off site. Supabase provides everything else: Auth for login, Postgres for the data, and private Storage buckets for announcement files and student submissions. There is no server code and no build step.
People log in with a Roll No or Teacher ID instead of an email: the app turns the ID into a hidden address (id@presentsir.app) for Supabase Auth, so no email is ever sent. Teachers create, reset and delete accounts from the website through Postgres functions called with supabase.rpc, which check that the caller is a teacher. Row Level Security on every table enforces the rules in the database itself, so students see only their own attendance and the classes a teacher added them to, and teachers manage only their own classes. To set up, run setup_all.sql once in the Supabase SQL Editor, paste your Supabase URL and anon key into index.html (the anon key is public by design; never use the service_role key), and upload the file to a GitHub repository with Pages turned on.
